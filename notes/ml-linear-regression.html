01Мотивация

Зачем нужно машинное обучение

Машинное обучение — наука, изучающая способы извлечения закономерностей из ограниченного количества примеров. Оно нужно там, где нельзя построить точную модель из понимания природы процесса (как второй закон Ньютона для силы), но зато есть много данных с примерами правильных решений.

Когда ML уместенНельзя вывести формулу ответа из знаний об устройстве мира; зависимость сложная, подобрать её вручную трудно; есть достаточно примеров с известными ответами.
Когда ML избыточенТочный алгоритм уже существует — незачем предсказывать силу по массе и ускорению, когда есть $F=ma$, или обучать сеть сортировке массива, когда есть сортировка слиянием.
!

ML также применяют, когда зависимость понятна, но сам расчёт ответа трудоёмок (классификация огурцов по фото вместо ручной проверки каждого), либо когда алгоритм решения вообще невозможно формализовать, а опытные люди справляются интуитивно (выплавка стали, игра в го — AlphaGo).

02Формализация

Объекты, признаки, обучающая выборка

Объект $x$ — то, для чего делается предсказание; множество всех объектов — пространство объектов $\mathbb{X}$. Ответ (целевая переменная) $y$ лежит в пространстве ответов $\mathbb{Y}$. Объекты сами по себе — абстрактные сущности; чтобы с ними работать, их описывают набором признаков — вектором чисел, категорий или более сложных структур.

Обучающая выборка $X = \{(x_1,y_1), \dots, (x_\ell, y_\ell)\}$ — примеры с известными правильными ответами. В матричном виде это матрица «объекты-признаки» $X \in \mathbb{R}^{\ell \times d}$: строки — объекты, столбцы — признаки.

Функция и функционал

Задача — построить алгоритм (модель) $a: \mathbb{X} \to \mathbb{Y}$, предсказывающий ответ. Чтобы понять, какой алгоритм лучше, вводится функционал качества (или ошибки, если его минимизируют). Самый популярный в регрессии — среднеквадратичная ошибка:

$$Q(a, X) = \frac{1}{\ell}\sum_{i=1}^{\ell}\big(a(x_i) - y_i\big)^2$$
Функционал определяет всё

Именно выбор функционала решает, какой алгоритм окажется «лучшим». Он не обязан быть выпуклым или дифференцируемым, но обязан отражать реальные требования к задаче — плохой выбор здесь обрекает все дальнейшие шаги на провал.

Семь этапов решения задачи ML

  3. Формирование выборки
  4. Выбор функционала ошибки
  5. Предобработка данных (масштабирование, борьба с выбросами и шумовыми признаками)
  6. Построение модели
  7. Оценивание качества модели

03Простейшее семейство

Линейная модель

Самое простое и тщательно изученное семейство алгоритмов — линейные модели: предсказание равно линейной комбинации признаков.

$$a(x) = w_0 + w_1 x_1 + \dots + w_d x_d = w_0 + \langle w, x \rangle$$

Приём для упрощения записи — добавить к каждому объекту фиктивный признак, равный единице (bias trick). Тогда вес при нём сам возьмёт на себя роль свободного коэффициента:

$a(x) = \langle w, x \rangle$
x = (1, x₁, …, xₙ)с фиктивной единицей
w = (w₀, w₁, …, wₙ)вектор весов

Почему линейные модели до сих пор используются

ПростотаБыстро и легко обучаются, подходят для больших объёмов данных.
Мало параметровКонтролируется риск переобучения; хорошо работают на зашумлённых и небольших выборках.
ИнтерпретируемостьКаждый вес — вклад признака в ответ; критично там, где нужна надёжность и объяснимость решения.

Линейность по параметрам, а не по признакам

Модель линейна именно по весам $w$ — сами признаки $x_i$ могут быть чем угодно:

численный признак напрямую преобразования: корень, логарифм степени: $x_2=x_1^2,\ x_3=x_1^3$ значения One-Hot-Encoding взаимодействия: $x_3=x_1 x_2$
Ключевая мысль

Это открывает пространство для манёвра: подставляя нелинейные преобразования признаков в линейную по весам формулу, можно моделировать существенно нелинейные зависимости — не меняя сам метод обучения.

04Подготовка данных

Признаки для линейных моделей

Линейная модель предполагает, что каждый признак влияет на ответ независимо и линейно. По умолчанию это редко выполняется — данные нужно подготовить.

Категориальные признаки: One-Hot Encoding

Категориальный признак $f_j(x)$ со значениями $C=\{c_1,\dots,c_m\}$ заменяется на $m$ бинарных индикаторов:

$$b_i(x) = [f_j(x) = c_i]$$
Осторожно: линейная зависимость

Признаки $b_1(x),\dots,b_m(x)$ линейно зависимы — их сумма всегда равна 1 ($b_1(x)+\dots+b_m(x)=1$). Чтобы избежать вырожденности, один из бинарных признаков обычно выбрасывают, но тогда новая, невиданная на обучении категория закодируется нулями по всем оставшимся — и это уже не будет соответствовать выброшенной категории однозначно.

Тексты: мешок слов (Bag of Words)

Все слова выборки нумеруются: $\{c_1,\dots,c_m\}$. Текст кодируется $m$ признаками, где $b_j(x)$ — число вхождений слова $c_j$:

$$a(x) = w_1 b_1(x) + \dots + w_m b_m(x) + \dots$$

Каждое вхождение слова $c_j$ сдвигает прогноз на $w_j$ — слово «престижный» в описании квартиры логично тянет цену вверх, а «плохой» — вниз.

Бинаризация числовых признаков

Если зависимость от числового признака нелинейна (например, цена квартиры растёт с приближением к метро только до определённого расстояния, а затем падает), признак можно разбить сеткой точек $\{t_1,\dots,t_m\}$ (с $t_0=-\infty$, $t_{m+1}=+\infty$) на интервалы-индикаторы:

$$b_i(x) = [t_{i-1} < x_j \le t_i], \quad i=1,\dots,m+1$$

Линейная модель поверх таких признаков находит собственный прогноз для каждого интервала — нелинейная по исходному признаку зависимость становится доступной линейной модели.

05Как измерять ошибку

Функции потерь для регрессии

MSE, RMSE, R²

$$\text{MSE}(a,X) = \frac{1}{\ell}\sum_{i=1}^\ell(a(x_i)-y_i)^2 \qquad \text{RMSE}(a,X) = \sqrt{\text{MSE}(a,X)}$$

MSE дифференцируем и потому самый популярный функционал, но плохо интерпретируется — не сохраняет единицы измерения (цена в рублях даёт MSE в квадратных рублях). RMSE решает это извлечением корня. Ни тот, ни другой не говорят, насколько хорошо решена задача — MSE=10 ужасен, если $y\in[0,1]$, и прекрасен, если $y\in(10^4,10^5)$.

$$R^2(a,X) = 1 - \frac{\sum_{i=1}^\ell(a(x_i)-y_i)^2}{\sum_{i=1}^\ell(y_i-\bar y)^2}$$ Доля дисперсии ответа, объяснённая моделью. $R^2 \approx 1$ — модель хорошо объясняет данные; $R^2 \approx 0$ — не лучше константного предсказания.

MAE и устойчивость к выбросам

$$\text{MAE}(a,X) = \frac{1}{\ell}\sum_{i=1}^\ell |a(x_i)-y_i|$$

$$\frac{\partial}{\partial a}|a-y| = \text{sign}(a-y) \qquad \frac{\partial}{\partial a}(a-y)^2 = 2(a-y)$$ Производная модуля не зависит от близости к ответу — при оптимизации MAE легко «перескочить» экстремум, обучение получается более долгим и сложным.
Почему так: минимум по константе

Если все объекты имеют одинаковые признаки, но разные $y_i$, минимум MSE достигается на среднем $a^*_{\text{MSE}}=\frac{1}{\ell}\sum y_i$, а минимум MAE — на медиане $a^*_{\text{MAE}}=\text{median}\{y_i\}$. Среднее чувствительно к выбросам, медиана — нет.

Гибриды: Huber loss и Log-Cosh

Хочется совместить гладкость MSE вблизи нуля с устойчивостью MAE вдали от него.

$$L_\delta(y,a) = \begin{cases} \frac{1}{2}(y-a)^2, & |y-a| < \delta \\ \delta\left(|y-a| - \frac{1}{2}\delta\right), & |y-a| \ge \delta \end{cases}$$

При $\delta \to 0$ Huber loss вырождается в MAE, при $\delta \to \infty$ — в MSE. Недостаток: вторая производная разрывна при $|y-a|=\delta$. У Log-Cosh $L(y,a)=\log\cosh(a-y)$ такого разрыва нет — тоже квадратичное поведение вблизи нуля и линейное вдали, но всюду гладко.

MSLE, MAPE и SMAPE

MSLE$L(y,a)=(\log(a{+}1)-\log(y{+}1))^2$ — штрафует за отклонение в порядке величины, а не в абсолютном значении; сильнее штрафует заниженные прогнозы.
MAPE$L(y,a)=\left|\frac{y-a}{y}\right|$ — относительная ошибка, легко интерпретируется («ошибка 50%»), не зависит от масштаба ответа. Несимметрична: занижение ограничено сверху единицей, завышение — нет.
SMAPE$L(y,a)=\dfrac{|y-a|}{(|y|+|a|)/2}$ — симметричная версия MAPE, исправляет асимметрию.

Квантильная функция потерь

Иногда цена занижения и завышения прогноза разная (например, дефицит товара в интернет-магазине обходится дороже, чем излишек на складе). Параметр $\tau \in [0,1]$ задаёт это соотношение:

$$\rho_\tau(z) = (\tau-1)[z<0]\,z + \tau[z\ge0]\,z = \left(\tau-\frac{1}{2}\right)z + \frac{1}{2}|z|$$
Вероятностный смысл

Если для каждого $x$ задано распределение ответов $p(y\mid x)$, то минимизация $\rho_\tau$ приводит алгоритм к приближению $\tau$-квантили этого распределения — обобщение того факта, что MSE даёт среднее ($\tau$-квантиль не определён явно, но это предельный аналог), а MAE даёт медиану (частный случай $\tau=0.5$).

06Обобщающая способность

Переобучение и оценка качества

Модель может показывать отличное качество на обучающей выборке и при этом плохо работать на новых данных — она переобучилась, подстроившись под шум конкретных примеров вместо реальной закономерности.

Наблюдение

У переобученной модели, как правило, получаются очень большие по модулю коэффициенты. Норма вектора весов — типичная величина, которую штрафуют для контроля сложности модели; этот подход называется регуляризацией (раздел 13).

Отложенная выборка (holdout)

Размеченные данные делятся на обучающую и контрольную части. Модель обучается на первой, качество измеряется на второй — так проверяется способность модели обобщать, а не просто запоминать.

Кросс-валидация

У holdout есть проблема: результат сильно зависит от конкретного разбиения. Кросс-валидация разбивает выборку на $k$ примерно равных блоков $X_1,\dots,X_k$; $i$-я модель обучается на всех блоках, кроме $i$-го, и проверяется именно на нём:

$$\text{CV} = \frac{1}{k}\sum_{i=1}^{k} Q\big(a_i(x), X_i\big)$$

Финальная модель

После того как кросс-валидация подтвердила, что метод обучения даёт хорошо обобщающие модели, финальную модель обычно обучают тем же способом уже на всех доступных данных — либо, если это невозможно, строят композицию (например, усреднение прогнозов) моделей $a_1,\dots,a_k$, полученных в процессе кросс-валидации.

07Обучение линейной регрессии

Точное решение через нормальное уравнение

С MSE и признаком-константой (свободный коэффициент не нужен отдельно) задача обучения — минимизация нормы невязки в матричном виде:

$$\frac{1}{\ell}\|Xw - y\|^2 \to \min_w$$

Распишем функцию потерь и продифференцируем по вектору весов:

$$L(w) = (Xw-y)^T(Xw-y) \qquad \frac{\partial L}{\partial w} = 2X^T(Xw-y)$$

Приравнивая производную к нулю (если столбцы $X$ линейно независимы), получаем явную формулу:

$$X^T(Xw-y)=0 \quad\Longrightarrow\quad w = (X^TX)^{-1}X^Ty$$
!

Это же выражение — псевдообратная матрица $X^+ = (X^TX)^{-1}X^T$. Когда $X$ квадратная и обратимая ($\ell=n$), решение точное: $w=X^{-1}y$. Когда $\ell \gg n$ (переопределённая система), $X^+$ даёт решение с наименьшей квадратичной ошибкой.

Когда формула не работает

Сложность обращенияОбращение матрицы — операция с кубической сложностью от числа признаков. При тысячах признаков вычисления становятся слишком трудоёмкими; решение — численные методы оптимизации.
ВырожденностьЕсли столбцы $X$ линейно зависимы (мультиколлинеарность), $X^TX$ вырождена или плохо обусловлена — обращение невозможно либо даёт неустойчивый результат. Лечится регуляризацией (раздел 13).

Аналитические формулы решения в машинном обучении — редкость: стоит заменить MSE на другой функционал, и найти явную формулу уже не получится. Поэтому нужен общий подход, работающий для широкого класса дифференцируемых функционалов — градиентный спуск.

08Общий метод оптимизации

Градиентный спуск

Градиент функции $f:\mathbb{R}^d\to\mathbb{R}$ — вектор её частных производных $\nabla f = \left(\frac{\partial f}{\partial x_j}\right)_{j=1}^d$. Он указывает направление наискорейшего роста функции, а антиградиент $-\nabla f$ — направление наискорейшего убывания.

Почему градиент — направление роста

Производная по направлению единичного вектора $v$ раскладывается через градиент:

$$\frac{\partial f}{\partial v} = \sum_{j=1}^d \frac{\partial f}{\partial x_j} v_j = \langle \nabla f, v \rangle = \|\nabla f\|\|v\|\cos\varphi = \|\nabla f\|\cos\varphi$$

где $\varphi$ — угол между градиентом и направлением $v$. Производная по направлению максимальна при $\varphi=0$ (вдоль градиента) и минимальна при $\varphi=180°$ (вдоль антиградиента) — отсюда и обоснование метода.

Ещё одно свойство: ортогональность линиям уровня

Разложив $f$ в ряд Тейлора вдоль линии уровня $S(x_0)=\{x\mid f(x)=f(x_0)\}$, получаем $\langle \nabla f, \varepsilon\rangle = o(\|\varepsilon\|)$ для смещения $\varepsilon$ вдоль этой линии. При $\|\varepsilon\|\to 0$ вектор $\varepsilon/\|\varepsilon\|$ стремится к касательной линии уровня — значит, градиент ей ортогонален. Это свойство пригодится, чтобы понимать вид траектории спуска на линиях уровня.

Алгоритм

$$w^{(k)} = w^{(k-1)} - \eta_k \nabla Q(w^{(k-1)})$$

Стартуем из точки $w^{(0)}$ (случайной или нулевой) и повторяем шаг до сходимости — критерием остановки может быть малость градиента $\|\nabla Q(w^{(k-1)})\|<\varepsilon$, малое изменение весов, либо рост ошибки на отложенной выборке.

Длина шага (learning rate)

Константа $\eta_k=c$Слишком большой шаг — риск перепрыгивать минимум; слишком маленький — долгая сходимость.
Убывающий $\eta_k=1/k$Простая монотонно убывающая схема.
Vowpal Wabbit$\eta_k = \lambda\left(\frac{s_0}{s_0+k}\right)^p$ — на практике достаточно настроить $\lambda$, остальным присвоить $s_0=1,\ p=0.5$.

Скорость сходимости

$$Q(w^{(k)}) - Q(w^*) = O(1/k)$$

Для выпуклых дифференцируемых функционалов с липшицевым градиентом и правильно подобранным шагом гарантируется сходимость к глобальному минимуму с этой скоростью; для невыпуклых функционалов — лишь сходимость к локальному минимуму или седловой точке.

09Масштабируем на большие данные

Оценивание градиента

Функционал в ML почти всегда — сумма ошибок по объектам: $Q(w)=\frac{1}{\ell}\sum_i q_i(w)$. Вычисление полного градиента $\nabla_w Q(w) = \frac{1}{\ell}\sum_i \nabla_w q_i(w)$ на каждом шаге трудоёмко при больших $\ell$ — но точность здесь не так важна, поскольку шаги в сторону антиградиента и так небольшие.

Стохастический градиентный спуск (SGD)

$$\nabla_w Q(w) \approx \nabla_w q_{i_k}(w) \qquad w^{(k)} = w^{(k-1)} - \eta_k \nabla q_{i_k}(w^{(k-1)})$$

Градиент оценивается по одному случайно взятому слагаемому. Это резко удешевляет шаг (на диске достаточно держать один объект за раз), но сходимость становится шумнее: параметры, оптимальные для одного объекта, не обязаны быть оптимальными в среднем. Для гарантий сходимости шаг должен убывать по условиям Роббинса–Монро:

$$\sum_{k=1}^\infty \eta_k = \infty \qquad \sum_{k=1}^\infty \eta_k^2 < \infty \qquad \mathbb{E}\big[Q(w^{(k)})-Q(w^*)\big] = O(1/\sqrt{k})$$

Точность оценки можно повысить, используя несколько случайных слагаемых сразу — mini-batch gradient descent, самый распространённый на практике вариант:

$$\nabla_w Q(w) \approx \frac{1}{n}\sum_{j=1}^n \nabla_w q_{i_{k_j}}(w)$$

Метод SAG (Stochastic Average Gradient)

Сочетает низкую стоимость шага SGD с высокой скоростью сходимости полного градиента. Идея: хранить вспомогательные переменные $z_i$ — последний посчитанный градиент каждого слагаемого; на шаге пересчитывается только один $z_{i_k}$, а используется среднее по всем $z_i$ (почти все из них — со старых шагов):

$$z_i^{(k)} = \begin{cases}\nabla q_i(w^{(k-1)}), & i=i_k \\ z_i^{(k-1)}, & \text{иначе}\end{cases} \qquad w^{(k)} = w^{(k-1)} - \eta_k \frac{1}{\ell}\sum_{i=1}^\ell z_i^{(k)}$$

SAG достигает той же скорости сходимости $O(1/k)$, что и полный градиентный спуск, при цене одного шага, сравнимой с SGD — но требует хранить последний градиент для каждого объекта выборки.

Оценивание без явных градиентов

Существуют методы, вообще не вычисляющие производные: случайный вектор $u$ на единичной сфере домножается на значение функции в этом направлении, $\nabla_w Q(w) \approx Q(w+\delta u)\,u$ — несмещённая оценка градиента сглаженной версии функционала. В глубоком обучении градиент иногда даже обучают предсказывать отдельной моделью на основе текущих параметров.

10Инженерные улучшения

Модификации градиентного спуска

Momentum (инерция)

Если линии уровня функционала сильно вытянуты, антиградиент меняет направление почти на противоположное на каждом шаге — осцилляции замедляют сходимость. Усреднение антиградиентов с предыдущих шагов гасит шум:

$$h_0 = 0 \qquad h_k = \alpha h_{k-1} + \eta_k \nabla_w Q(w^{(k-1)}) \qquad w^{(k)} = w^{(k-1)} - h_k$$

Если знак градиента по координате постоянно меняется, вектор инерции по ней близок к нулю (осцилляции гасятся); если знак стабилен — вектор инерции растёт, и шаги в этом направлении становятся крупнее.

AdaGrad и RMSprop

Градиентный спуск чувствителен к выбору длины шага. AdaGrad подбирает свою длину шага для каждой координаты — тем меньшую, чем длиннее были предыдущие шаги по ней:

$$G_{kj} = G_{k-1,j} + \big(\nabla_w Q(w^{(k-1)})\big)_j^2 \qquad w_j^{(k)} = w_j^{(k-1)} - \frac{\eta_t}{\sqrt{G_{kj}+\varepsilon}}\big(\nabla_w Q(w^{(k-1)})\big)_j$$

Хорошо подходит для разреженных задач — по редко ненулевым признакам шаги остаются крупными. Недостаток: $G_{kj}$ монотонно растёт, шаги могут остановиться раньше, чем найден минимум. RMSprop решает это экспоненциальным затуханием накопленных градиентов вместо их полной суммы:

$$G_{kj} = \alpha G_{k-1,j} + (1-\alpha)\big(\nabla_w Q(w^{(k-1)})\big)_j^2$$

Adam

Объединяет обе идеи: накапливает (со сглаживанием) сами градиенты, как momentum — для устранения осцилляций, и накапливает квадраты градиентов, как RMSprop — для адаптивной длины шага по каждому параметру. На практике — де-факто стандартный оптимизатор для глубоких моделей.

11Смена постановки

Вероятностный взгляд на классификатор

Для бинарной классификации ($y\in\{0,1\}$) удобно считать $X$ и $Y$ случайными величинами и построить модель, предсказывающую вероятность:

$$P(Y=1\mid \mathbf{x}) = \hat f(\mathbf{x})$$
Пример

$X=$ (число кликов раньше, время активности, доход) для задачи предсказания клика по рекламе; $\hat f(\mathbf{x})$ — вероятность того, что человек с такими характеристиками кликнет.

Правдоподобие — вероятность получить именно такую обучающую выборку, если верить предсказаниям модели:

$$\prod_{i=1}^\ell P(Y=y_i\mid \mathbf{x}_i) \to \max_{\mathbf{w}}$$

Теорема из статистики (метод максимального правдоподобия) гарантирует: параметры, максимизирующие правдоподобие, дают хорошую модель. Логарифмирование не меняет точку максимума, но превращает произведение в сумму:

$$\ln\left(\prod_{i=1}^\ell P(Y=y_i\mid\mathbf{x}_i)\right) \to \max_{\mathbf{w}}$$

Меняя знак, получаем задачу минимизации — тот же функционал, что и во всех предыдущих разделах:

$$L(\mathbf{w}) = -\sum_{i=1}^\ell \ln\big(P(Y=y_i\mid\mathbf{x}_i)\big) \to \min_{\mathbf{w}}$$
Что мы сделали

Максимизация правдоподобия даёт статистически хорошие веса. Изменив знак и прологарифмировав, мы получили функцию потерь, минимизация которой эквивалентна максимизации правдоподобия — теперь можно применять уже знакомый градиентный спуск, только к другой модели.

12Классификация через сигмоиду

Логистическая регрессия

Модель ищется в виде линейной комбинации признаков, пропущенной через сигмоиду — она сжимает любое вещественное число в интервал $(0,1)$, где и живут вероятности:

$\hat f(\mathbf{x}) = \sigma\!\left(\sum_{i=0}^n w_i x_i\right)$
σ(x) = 1/(1+e⁻ˣ)сигмоида
!

Модель называется регрессией, а не классификацией, потому что она в первую очередь предсказывает вероятность — вещественное число; порог 0.5 (или другой) для получения бинарной метки применяется уже поверх этого предсказания.

Функция потерь: LogLoss

Для двух классов $y_i\in\{0,1\}$ вероятность правильного класса можно записать одной формулой, не различая случаи:

$$\ln P(Y=y_i\mid\mathbf{x}_i) = y_i\ln\big(\hat f(\mathbf{x}_i)\big) + (1-y_i)\ln\big(1-\hat f(\mathbf{x}_i)\big)$$

Подставляя в общую формулу функции потерь из предыдущего раздела, получаем LogLoss:

$$L(\mathbf{w}) = -\sum_{i=1}^\ell \Big[y_i\ln(\hat f(\mathbf{x}_i)) + (1-y_i)\ln(1-\hat f(\mathbf{x}_i))\Big] \to \min_{\mathbf{w}}$$

Градиент логистической регрессии

Производная сигмоиды имеет удобный вид $\sigma'(x)=\sigma(x)(1-\sigma(x))$, откуда:

$$\frac{\partial \hat f(\mathbf{x}_i)}{\partial w_1} = \hat f(\mathbf{x}_i)\big(1-\hat f(\mathbf{x}_i)\big)\, x_{i1}$$

Подставив это в производную LogLoss по цепному правилу и упростив дроби, получаем чистое выражение без логарифмов:

$$\frac{\partial L}{\partial w_1} = -\sum_{i=1}^\ell x_{i1}\Big[y_i\big(1-\hat f(\mathbf{x}_i)\big) - (1-y_i)\hat f(\mathbf{x}_i)\Big]$$

Множитель в скобках — это, по сути, «ошибка» предсказания вероятности (для $y_i=1$ остаётся $1-\hat f(\mathbf{x}_i)$, для $y_i=0$ — $-\hat f(\mathbf{x}_i)$); чем увереннее модель ошибается, тем больше вклад объекта в градиент.

Обобщение на много классов: Softmax

При $m$ классах для каждого класса заводится свой вектор весов $\mathbf{w}^k$, и все линейные комбинации (логиты) переводятся в распределение вероятностей через softmax:

$$logits(\mathbf{x}) = \begin{pmatrix}\mathbf{w}^1\cdot\mathbf{x}\\ \vdots \\ \mathbf{w}^m\cdot\mathbf{x}\end{pmatrix} \qquad \text{Softmax}(\alpha) = \left(\frac{e^{\alpha_1}}{\sum_{i=1}^m e^{\alpha_i}}, \dots, \frac{e^{\alpha_m}}{\sum_{i=1}^m e^{\alpha_i}}\right)$$
$$P(Y=k\mid\mathbf{x}) = \hat f_k(\mathbf{x}) = \frac{e^{\sum_{i=0}^n w_i^k x_i}}{\sum_{k=1}^m e^{\sum_{i=0}^n w_i^k x_i}}$$

Softmax гарантирует, что все выходы неотрицательны и в сумме дают единицу — законное распределение вероятностей по классам, которое затем так же подставляется в общую функцию потерь $L(\mathbf{w})=-\sum\ln P(Y=y_i\mid\mathbf{x}_i)$.

13Контроль сложности модели

Регуляризация

Если столбцы матрицы $X$ линейно зависимы (мультиколлинеарность), существует такой ненулевой вектор $\beta$, что $X\beta=0$. Тогда бесконечно много векторов весов дают одинаковые предсказания:

$$\forall c\in\mathbb{R}: \quad \mathbf{x}\cdot(\mathbf{w}+c\beta) = \mathbf{x}\cdot\mathbf{w} + c\,\mathbf{x}\cdot\beta = \mathbf{x}\cdot\mathbf{w}$$
Почему это плохо

Решение перестаёт быть единственным: веса могут разъезжаться сколь угодно далеко (в направлении $\beta$), не меняя качество на обучающей выборке. Именно это стоит за наблюдением из раздела 6 — переобученные модели получают неадекватно большие коэффициенты.

Weight Decay: L1 и L2 регуляризация

Предположим, что веса не должны быть большими по модулю, и добавим это как штраф прямо в функцию потерь ($\beta$ — сила регуляризации):

$$L_2\text{-регуляризация:}\quad L(\mathbf{w}) = \sum_{i=1}^\ell(\mathbf{x}_i^T\mathbf{w}-y_i)^2 + \beta\sum_{j=1}^n w_j^2$$ $$L_1\text{-регуляризация:}\quad L(\mathbf{w}) = \sum_{i=1}^\ell(\mathbf{x}_i^T\mathbf{w}-y_i)^2 + \beta\sum_{j=1}^n |w_j|$$

Штраф превращает вырожденную задачу в невырожденную: движение весов вдоль направления $\beta$ теперь увеличивает норму штрафа, поэтому у минимума появляется единственное решение.

Как меняется градиент

$$\frac{\partial L}{\partial w_1}\Big|_{L_2} = \sum_{i=1}^\ell 2(\mathbf{x}_i^T\mathbf{w}-y_i)x_{i1} + 2\beta w_1$$ $$\frac{\partial L}{\partial w_1}\Big|_{L_1} = \sum_{i=1}^\ell 2(\mathbf{x}_i^T\mathbf{w}-y_i)x_{i1} + \beta\,\text{sign}(w_1)$$

$L_2$-штраф на каждом шаге «стягивает» вес пропорционально его текущему значению — отсюда и название Weight Decay. $L_1$-штраф толкает вес к нулю с постоянной силой независимо от его величины, из-за чего $L_1$-регуляризация склонна обнулять несущественные веса полностью, выполняя неявный отбор признаков.

14Последний штрих перед обучением

Нормализация признаков

Признаки приводятся к одному масштабу вычитанием среднего и делением на стандартное отклонение (z-score):

$$x_{ij}^{\text{new}} = \frac{x_{ij}-\mu_j}{\sigma_j}$$ $\mu_j$ — среднее $j$-го признака на обучающей выборке, $\sigma_j$ — его стандартное отклонение.
Градиентный спускПлохо сходится на признаках с сильно разным масштабом — линии уровня функционала становятся сильно вытянутыми эллипсами, и антиградиент указывает почти перпендикулярно направлению к минимуму.
РегуляризацияШтраф $\sum w_j^2$ или $\sum|w_j|$ одинаково давит на все веса — если признаки в разных масштабах, регуляризация начинает несправедливо сильнее давить на веса при «мелких» по масштабу признаках.
ИнтерпретируемостьПосле нормализации величина веса $w_j$ становится сопоставимой мерой важности признака $j$ — до нормализации сравнивать веса между собой некорректно.

Самое важное

Разобрано:

  • Постановка задачи ML: объекты, признаки, функционал качества, типы задач обучения с учителем и без
  • Линейная модель: bias trick, линейность по параметрам, а не по признакам, one-hot/bag-of-words/бинаризация
  • Функции потерь регрессии: MSE/RMSE/R², MAE, Huber/Log-Cosh, MSLE, MAPE/SMAPE, квантильная
  • Переобучение, holdout, кросс-валидация
  • Точное решение через нормальное уравнение и его ограничения
  • Градиентный спуск: свойства градиента, схемы шага, SGD/mini-batch/SAG, momentum/AdaGrad/RMSprop/Adam
  • От линейной регрессии к логистической: правдоподобие, MLE, LogLoss, softmax для многих классов
  • Регуляризация (L1/L2) и нормализация признаков

Что стоит запомнить:

  • Линейная модель линейна по весам, а не по исходным признакам — нелинейность моделируется через признаковую инженерию
  • Выбор функции потерь определяет, что именно приближает обученная модель: MSE → среднее, MAE → медиана, квантильная функция → произвольная квантиль
  • Аналитическое решение существует только для MSE без ограничений; во всех остальных случаях — градиентный спуск
  • Логистическая регрессия — та же линейная модель, но с сигмоидой и вероятностной интерпретацией выхода
  • Регуляризация решает задачу единственности решения при мультиколлинеарности и одновременно борется с переобучением
