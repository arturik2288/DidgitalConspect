# Цифровые конспекты

Личный сайт для HTML-конспектов по предметам. Статика, без сборки — можно открыть
`index.html` напрямую или задеплоить на GitHub Pages / Netlify как есть.

Слева — постоянный сайдбар с тремя разделами (Математика / IT / Экономика), у каждого
своя цветовая тема. Главная страница — просто описание сайта со ссылками на разделы.

## Структура

```
index.html               — главная страница (описание сайта + сайдбар)
sections/math.html        — раздел «Математика» (ч/б тема)
sections/it.html          — раздел «IT» (тёмная тема, неоновые акценты)
sections/economics.html   — раздел «Экономика» (тёплая кремовая тема)
assets/sidebar.css        — стили сайдбара (общие для всех страниц)
assets/section.css        — структура страницы раздела (поиск + фильтры + карточки)
assets/theme-*.css        — цветовые переменные конкретного раздела
assets/note.css            — общие стили для страниц конспектов
assets/app.js              — логика поиска/фильтрации на странице раздела
assets/data.js             — манифест конспектов (список карточек)
notes/                      — сами HTML-конспекты
```

## Как добавить новый конспект

1. Сделайте HTML-файл конспекта (можно взять любой файл из `notes/` как шаблон —
   он уже подключает `assets/note.css` и оформлен в общем стиле) и положите его в `notes/`.
   Ссылку «← Раздел ...» в шапке конспекта направьте на соответствующую страницу раздела
   (например `../sections/math.html`).
2. Откройте `assets/data.js` и добавьте новый объект в массив `NOTES`:

```js
{
  id: "my-note",
  title: "Название темы",
  division: "math",        // "economics" | "math" | "it" — в каком разделе показать
  category: "Предмет",
  date: "2026-09-15",
  displayDate: "15 сен 2026",
  description: "Короткое описание в 1-2 предложения.",
  tags: ["тег1", "тег2"],
  file: "notes/my-note.html",
  example: false
}
```

Карточка и фильтр по предмету появятся на странице нужного раздела автоматически —
категории собираются из `data.js`, ничего больше редактировать не нужно. Флаг
`example: true` добавляет плашку «ПРИМЕР» — используйте для демонстрационных материалов.

## Добавление нового раздела

Если понадобится четвёртый раздел: скопируйте `sections/math.html` как шаблон, создайте
`assets/theme-<name>.css` с новыми переменными цвета, добавьте пункт в сайдбар (блок
`.sidebar-nav`) на всех страницах — `index.html` и во всех файлах `sections/*.html`.
