# Цифровые конспекты

Личный сайт для HTML-конспектов по предметам. Статика, без сборки — можно открыть
`index.html` напрямую или задеплоить на GitHub Pages / Netlify как есть.

## Структура

```
index.html        — главная страница (поиск + фильтры + карточки)
assets/style.css   — стили главной страницы
assets/note.css    — общие стили для страниц конспектов
assets/app.js      — логика поиска/фильтрации
assets/data.js     — манифест конспектов (список карточек)
notes/             — сами HTML-конспекты
```

## Как добавить новый конспект

1. Сделайте HTML-файл конспекта (можно взять любой файл из `notes/` как шаблон —
   он уже подключает `assets/note.css` и оформлен в общем стиле) и положите его в `notes/`.
2. Откройте `assets/data.js` и добавьте новый объект в массив `NOTES`:

```js
{
  id: "my-note",
  title: "Название темы",
  category: "Предмет",
  date: "2026-09-15",
  displayDate: "15 сен 2026",
  description: "Короткое описание в 1-2 предложения.",
  tags: ["тег1", "тег2"],
  file: "notes/my-note.html",
  example: false
}
```

Карточка и фильтр по предмету появятся на главной автоматически — категории собираются
из `data.js`, ничего больше редактировать не нужно. Флаг `example: true` добавляет
плашку «ПРИМЕР» — используйте для демонстрационных материалов.
